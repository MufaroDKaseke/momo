The share-card generator uses Fira Code Bold and Inter Regular, the same font families as the website. These static TrueType instances were downloaded through the Google Fonts API on 2026-11-03. The original uncompressed TrueType payloads were extracted from the API's legacy EOT containers without modifying font data.

Both families are distributed under the SIL Open Font License 1.1; their original licence notices are included here.

Sources:

- https://fonts.google.com/specimen/Fira+Code
- https://github.com/google/fonts/tree/main/ofl/firacode
- https://fonts.google.com/specimen/Inter
- https://github.com/google/fonts/tree/main/ofl/inter

The files are generation-time assets. They are not loaded by site visitors; the website's existing Google Fonts stylesheet remains unchanged.
